# Data access

No participant-level data are distributed by this repository, including processed intermediate records. The CSV files are aggregate manuscript and model summaries, not analysis datasets. Access to source data is independent of access to this code repository.

- HRS: https://hrs.isr.umich.edu/data-products — obtain the specific core and RAND products described in the manuscript through the official access process. The HRS 2022 release decision remains open. Users must follow current conditions of use, including AI-related restrictions.
- SHARE: https://share-eric.eu/data/ — registered access is required. The project has Release 9.0.0 Waves 5, 6, 8 and 9 and longitudinal weights. Possession of official design modules does not mean that the official PSU/stratum sensitivity model has been completed.
- CHARLS: https://charls.pku.edu.cn/en/ — obtain the applicable waves and documentation through the official registration and access process.

The manuscript Data availability section provides product-specific links and documentation. This repository does not grant cohort access or permission to redistribute original or derived individual records. Authorised analysts must independently determine a compliant local processing environment. Do not upload data, imputation objects, private logs or credentials to issues or pull requests.
